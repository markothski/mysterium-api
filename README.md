# Mysterium — Calendar & Intentions Data


Static JSON files containing the Pope’s monthly prayer intentions and liturgical feasts, designed for offline synchronization within the Mysterium app.


## СStructure


{year}/
├── intentions/          
│   ├── ru.json     for ru & kz      
│   ├── be.json
│   ├── pl.json
│   ├── sk.json
│   └── hr.json
└── feasts/             
    ├── ru.json
    ├── kz.json
    ├── be.json
    ├── pl.json
    ├── sk.json
    └── hr.json
